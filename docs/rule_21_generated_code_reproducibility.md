Here is the requested information regarding the "Generated-code law" under Rule 21 from `AGENTS.md`:

### 4-Step Reproducibility Process
The required process for reproducing generated code is:
1. clean generation
2. digest output
3. regenerate
4. verify byte-identical output

### Consequences of Hand-Editing
According to the rules:
- **Hand-editing generated output is strictly prohibited.**
- If hand-edited files result in unexplained drift, the generated files **invalidate standing**.
