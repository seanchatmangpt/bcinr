## wasm4games: The Game-Pattern Foundry

`crates/wasm4games` is a branchless, `no_std`, engine-agnostic game-pattern foundry: game
behaviors become bounded byte-class state + branchless kernels (on `bcinr-logic`) that emit
object-centric evidence (OCEL, OTEL, FNV receipts, deterministic replay). **Its kernels are
generated by ggen, never hand-coded.** Start here:

- **[The GGEN-Only User Surface (The Covenant)](explanation/ggen-only-user-surface.md)** — read this first; the rule that governs every change.
- **[Add a Pattern (the ggen way)](tutorials/wasm4games-add-a-pattern.md)** — the hands-on path: declare in RDF, run `ggen sync`, verify.
- [The Game-Pattern Foundry (overview)](explanation/wasm4games-overview.md) — the model, the doctrine, and the wasm4pm relationship.
- [Run Real wasm4pm Admission](how-to/wasm4games-run-wasm4pm-admission.md) — real admit/refuse via the workspace-excluded bridge.
- [Pattern Catalog (reference)](reference/wasm4games-patterns.md) — the full `PATTERN_REGISTRY` table and evidence types.
