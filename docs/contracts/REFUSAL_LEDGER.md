# Refusal Ledger

GENERATED by `ggen sync` from `ontology/bcinr.ttl` + imports -- DO NOT EDIT.

Every condition under which this system declines to answer, with its live Rust
path and whether a witness for it runs. Manufactured from the same admitted
facts as the enum definitions (`crates/bcinr-guarded/src/taxonomy.rs`), the
runtime bindings whose matches have no `_` arm
(`crates/bcinr-guarded/src/runtime_binding.rs`), and the executable falsifiers
(`crates/bcinr-guarded/tests/generated_falsifiers.rs`).

A document that disagrees with the code it describes is the failure mode this
file exists to make unrepresentable. `docs/contracts/CMCA_CONTRACT.md` once
documented a refusal the code did not return, and carried a hand-written notice
saying so -- because prose cannot fail, that notice was the only mechanism
available, and it decayed into part of the document.

## Witness status

- **runs** -- an adversarial input is recorded against the variant and a
  generated test asserts that it produces exactly this refusal.
- **no witness** -- no input is known to reach it. `ontology/shapes.ttl` will
  not admit this state without a written argument, which is reproduced below.
