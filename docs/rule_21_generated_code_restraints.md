Based on my research of the `AGENTS.md` file, here is the explanation of the specific requirements in the Generated-code law (Rule 21) regarding "no fixture-specific identifiers" and "disassembly inspection", and why they are necessary for reproducible generation:

### 1. "No fixture-specific identifiers"
* **The Requirement**: Generated authoritative code must not contain any variables, temporary paths, timestamps, random seeds, or identifiers that are specific to a local test fixture or environment.
* **Why it's necessary for reproducible generation**: Rule 21 mandates a strict reproducibility process: `clean generation → digest output → regenerate → verify byte-identical output`. If the generator embeds fixture-specific identifiers, the output will vary between different machines, CI runs, or test executions. This would break byte-for-byte reproducibility, resulting in "unexplained drift," which the constitution dictates will immediately invalidate the project's standing.

### 2. Passing "disassembly inspection"
* **The Requirement**: It is not enough for the generated source code to pass source-level audits (like `CC=1` and the cheat scanner). The compiled object code derived from the generated source must also pass an exact, production-profile disassembly audit (as defined in Rule 20) to prove it contains no conditional jumps, loop backedges, allocator calls, or panic paths.
* **Why it's necessary for reproducible generation**: The overarching mission of BCINR (Rule 1) is to guarantee a **"fixed instruction shape"** at the machine-code level, not just the source level. Even if the generated Rust source appears branchless, the compiler might introduce bounds checks (panic paths) or optimization-induced branches when compiling generated arrays or unrolled loops. Disassembly inspection ensures that the generator reliably and reproducibly outputs source code that maps directly to deterministic, branchless machine code across all supported targets, guaranteeing structural reproducibility down to the binary level.
