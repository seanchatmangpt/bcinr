`main` at `d52e7ca` (v26.9.25). Every requirement below was measured, not assumed.

## Explicitly not in scope

- **Publishing.** All library crates, including `bcinr-cmca` and `bcinr-guarded`, are
  publishable as of 26.9.28 (release-owner decision) so that `bcinr-powl` and `bcinr-pddl`
  resolve from crates.io. `cargo publish --dry-run --workspace` verifies the set in
  dependency order. The CMCA-102/CMCA-114 authority chain remains `#[deprecated]`
  pending Hoare-logic verification. Actual upload is not done by this PR.
- **CMCA-102/CMCA-114.** The allocator authority chain is still `#[deprecated]`
  pending Hoare-logic verification. Lifting that needs the proofs, not a version bump.
- **Signing-key exposure.** The revoked key stays revoked; history is not rewritten
  (see `docs/security/key-exposure-v26.9.25.md`).
- **`generic_const_exprs` warning** in `bcinr-powl` under the next-generation trait
  solver is a nightly toolchain issue and is left as is.
